# 주간 상품 유지보수 계약

월요일 09:00 KST의 기존 `crawler.yml` / `crawler/schedule.json` 경로를 사용한다.
샤넬·프라다·보테가·롤렉스·반클리프·루이비통·디올 모두 같은 중앙 분기를 따른다.

- 기존 한국 SKU: 익명 공개 대조한 등록 목록으로 식별한다. 원사이트의 정확 SKU/원화/공식 URL을 검증하고 기존 한국 market의 가격·확인시각만 PATCH한다. 이름/색상/소재/치수/모델/미디어/해외 market은 변경하지 않는다. 이미지 HTTP·CPU 누끼·R2 업로드는 실행하지 않는다.
- 신규 한국 SKU: 기존 통합 레코드 계약과 CPU 원본 누끼·R2·DB·익명 공개 검증을 모두 유지한다. 가격 전용 marker로 신규 상품을 등록할 수 없다.
- 해외 7국: 한국에 등록한 같은 제품코드의 현지 가격·통화·공식 URL만 수집하는 기존 어댑터를 유지한다.
- 가격 이력은 변경 시에만 추가한다. 미확인 가격으로 정상 가격을 지우거나 더 최신 가격을 덮어쓰지 않는다. 미확인/최신값 보존은 신규 가격 확보와 별도 상태로 보고한다.

`crawler-daily.mjs`가 주간 유지보수 문맥을 전달하고 중앙 pipeline이 등록 manifest를 서비스 역할/익명 역할로 대조한다. 모든 이미지 호출은 공통 processor에서 **worker 시작 전** 기존 SKU를 제외한다. 저장도 `ingest-weekly-products.mjs`가 기존/신규를 분할하고 원래 신규 저장기를 재사용한다. 수동 이미지 복구는 이 주간 문맥을 설정하지 않으므로 원래 검증 경로를 유지한다.

`REGISTERED_PRICE_PUBLIC_VERIFIED`는 기존 SKU의 가격만 공개 대조했다는 뜻이다. `PUBLIC_CATALOG_VERIFIED` 또는 전체발견 완료로 바꾸지 않는다. 원사이트 거부·파서 오류·독립 전체발견 미완료는 그대로 실패/부분 상태다. Actions 성공이나 표본 성공을 정기 전체 수집 성공으로 보고하지 않는다.

디올은 정상 출처 배치를 저장한 뒤 다음 배치를 요청한다. 후속 페이지 실패가 앞선 정상 가격의 적재를 없애지 않는다. 과거 거부 URL 캐시와 원본 이미지 실패 입력 해시는 유지한다. 한국 신규 발견과 기존 가격 갱신을 분리하며 기존 등록 사진/속성을 복구 작업처럼 재처리하지 않는다.

검증: `node scripts/test-registered-maintenance.mjs`는 7브랜드 모두 이미지 요청 0건, 가격 PATCH 허용 필드, 익명 공개/이력 대조, 기존 속성/미디어 보존, 미확인 가격 보존, 미등록 marker 거부와 신규 이미지 관문을 시험한다. 실제 실행 결과와 별도로 기록한다.
